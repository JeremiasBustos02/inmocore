# InmoCore

Plataforma multi-tenant para inmobiliarias, con sitio público de propiedades y panel de administración.

## Desarrollo

```bash
pnpm install
pnpm dev
```

Las variables se documentan en `.env.example`. Los comandos disponibles están en `package.json`.
